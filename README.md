# 一箭又一箭 · 太空探索（NovaArrowAdventure）

软件工程课程第二次个人作业：使用 Python 和 AIGC 辅助开发的点击式箭头解谜游戏。

本 README 对应上传的单文件版本。相比第一版，本版将棋盘从 5×5 扩展到 7×7，将关卡从 3 个扩展到 7 个，并加入火箭造型、不同关卡背景、暂停、提示、计时及本次运行内的最佳纪录。

## 游戏简介

玩家点击带方向的火箭，让它沿上、下、左、右方向飞出棋盘。只有火箭与棋盘边界之间不存在其他火箭时才能成功消除；如果存在阻挡，会播放碰撞与返回动画，并消耗一次失误机会。

每关有 3 次失误机会，用星星表示。清空当前关卡后自动进入下一关；第 7 关结束后显示最终通关界面。失误机会耗尽时显示失败界面，可以重新挑战当前关卡。

## 主要功能

- 900×700 游戏窗口和 7×7 网格棋盘。
- 四方向路径检测、火箭飞出、尾焰与拖尾效果。
- 碰撞返回、爆炸粒子和扣星特效。
- 7 个太空主题关卡与不同的背景。
- 当前关卡、剩余火箭数量、剩余星星和本关计时显示。
- 暂停/恢复、提示可发射火箭、重开当前关。
- 通关时比较并更新本关最佳用时。

## 安装和运行

下载仓库后，在项目目录执行：

```bash
python -m pip install pygame-ce==2.5.8
```

PyCharm 中选择安装了 pygame-ce 的项目解释器，右键 main.py 运行。已经安装 pygame-ce 时，无需再安装 pygame，二者导入名均为 pygame。


## 操作说明

| 操作 | 效果 |
| --- | --- |
| 点击“开始探索” | 从第一关开始 |
| 点击火箭 | 检查前方阻挡并尝试发射 |
| 点击“重新开始” | 重置当前关布局、星星和计时 |
| 点击“暂停”或游戏中按 Esc | 进入暂停界面 |
| 暂停界面点击“继续探索”或按 Esc | 恢复游戏 |
| 暂停界面点击“重新开始” | 重开当前关 |
| 点击“提示” | 高亮一个可以安全发射的火箭 |
| 失败后点击“重新挑战” | 重开当前关，不回第一关 |
| 最终通关点击“重新探索” | 从第一关重新开始 |
| 关闭窗口 | 退出程序 |

火箭动画进行时不接受另一枚火箭的发射请求。提示通过扫描剩余火箭，找到前方没有阻挡的对象。

## 计时与最佳纪录说明

通关时以当前用时与 `best_times[current_level]` 比较，更短则更新。再次进入对应关卡时，可以在界面看到已记录的最佳时间。

**纪录仅保存在内存里，退出程序后会清空。** 本版没有 JSON 存档、历史成绩文件或独立的“新纪录”弹窗；前六关清空后自动进入下一关，没有单关结算页面。

暂停时停止火箭逻辑，恢复后通过 `paused_total` 排除暂停时长。但当前源码在暂停分支仍刷新显示时间，因此暂停画面上的计时会继续变化，恢复后再扣除暂停时段；这是后续需修复的显示问题。

## 核心实现

每个火箭使用 `[row, col, direction, color_index]` 表示。鼠标坐标减去棋盘偏移后整除格子尺寸，即可得到行列位置。

`get_blocking_arrow()` 从相邻格开始，沿朝向扫描到边界，用 `find_arrow()` 查找最近的阻挡火箭。无阻挡时从静态棋盘移除并播放飞行动画；有阻挡时播放碰撞、变色与回退过程，再放回棋盘。`check_level_complete()` 更新最佳用时，并自动切换关卡或进入最终通关状态。

游戏状态包括 start、game、pause、fail、win。游戏循环每帧读取输入、更新状态并绘制界面。
