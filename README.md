# 一箭又一箭（NovaArrowAdventure）

软件工程课程第二次个人作业：利用 AIGC 辅助开发的 Python 点击式箭头解谜小游戏。

本 README 对应第一次上传的单文件版本：5×5 棋盘、3 个关卡。

## 游戏简介

玩家观察箭头方向和相互阻挡关系，通过鼠标点击箭头，使所有箭头依次飞出棋盘。

- 箭头具有上、下、左、右四种方向。
- 前方同一行或同一列没有其他箭头时，箭头飞出并消失。
- 前方有阻挡时，箭头向阻挡处移动再返回，扣除一次失误机会。
- 每关初始有 3 次失误机会，使用星星和数字显示。
- 清空前两关后自动进入下一关；清空第三关显示最终通关界面。
- 失误机会耗尽时显示失败界面。

## 当前功能

- 开始界面、游戏界面、最终通关界面、失败界面。
- 鼠标选中箭头、四方向路径检测、飞出动画和碰撞返回动画。
- 当前关卡、剩余箭头数量和剩余失误次数显示。
- 星星闪烁与扣星特效。
- 游戏中重新开始当前关卡。

本版本尚未加入暂停、提示、计时、纪录保存或音效。前两关自动切换，没有独立的本关结算弹窗。

## 安装和运行

1. 下载或克隆仓库，将源码命名为 `main.py`。
2. 在项目目录打开终端，安装依赖：

```bash
python -m pip install pygame-ce==2.5.8
```

3. 启动：

```bash
python main.py
```

PyCharm 用户请选择安装了 pygame-ce 的解释器，右键 main.py → Run。
如果虚拟环境中已经安装了 pygame-ce，不需要再安装另一份 pygame；两者使用相同的导入名。
如果保留上传时的文件名，也可以执行 `python "main(1).py"`。

## 操作说明

| 操作 | 效果 |
| --- | --- |
| 点击“开始游戏” | 从第一关开始 |
| 点击棋盘中的箭头 | 检查前方路径并播放飞出或碰撞返回动画 |
| 游戏中点击“重新开始” | 恢复当前关初始布局和 3 次失误机会 |
| 失败后点击“重新挑战” | 从第一关重新开始（当前源码的实际行为） |
| 通关后点击“再玩一次” | 从第一关重新开始 |
| 点击窗口关闭按钮 | 退出程序 |

动画播放期间暂不接受新的箭头发射。操作时以当前箭头的朝向判断前方是否被阻挡。

字体是唯一会尝试读取的外部文件，加载顺序如下：

1. `C:/Windows/Fonts/msyh.ttc`（微软雅黑）；
2. `C:/Windows/Fonts/simhei.ttf`（黑体）；
3. Pygame 默认字体。

Windows 已有这些字体时无需随仓库上传。不要把系统字体直接复制到仓库分发。若两种中文字体都不存在，程序会使用默认字体，但中文可能显示成方框。macOS/Linux 用户或缺少中文字体的电脑，需要另行配置可合法分发的中文字体并修改字体路径；本版未做此跨平台修改。

## 实现思路

箭头以 `[行, 列, 方向]` 表示，每个关卡由一组箭头组成。鼠标位置减去棋盘左上角偏移后，通过整除单格大小得到行列坐标。

`get_blocking_arrow()` 沿箭头朝向从相邻格逐格检查到边界，调用 `find_arrow()` 查找占用，返回最近阻挡物。没有阻挡则播放飞出动画；有阻挡则播放移动与返回动画，返回原位后恢复箭头并扣除一次失误机会。
