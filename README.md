软件工程课程第二次个人作业：使用 Python 与 AIGC 辅助开发的点箭头解谜游戏。

本文对应上传的单文件版本，保留 7×7 棋盘和 7 个太空主题关卡。

## 游戏简介

观察火箭方向和相互阻挡关系，通过鼠标点击，让火箭依次飞出棋盘。方向包括上、下、左、右。

- 前方同一行或同一列没有其他火箭：飞出并消除。
- 存在阻挡：火箭碰撞返回，消耗一颗星。
- 每关初始 3 颗星，耗尽后失败。
- 清空本关后显示结算弹窗，点击“下一关”继续。
- 第七关结束后显示“探索完成”与最终特效，可返回首页。

## 安装和运行

在项目目录执行：

```bash
python -m pip install pygame-ce==2.5.8
python main.py
```

PyCharm 中选择已安装 pygame-ce 的解释器，右键 main.py 运行。如果已安装 pygame-ce，无需另外安装 pygame，二者导入名相同。

## 操作说明

| 操作 | 效果 |
| --- | --- |
| 首页“开始探索” | 从第一关开始 |
| 点击火箭 | 按其朝向尝试发射 |
| “重新开始” | 重置当前关卡布局、星星和计时 |
| “暂停”或游戏中按 Esc | 暂停火箭逻辑，进入暂停页面 |
| 暂停页“继续探索”或按 Esc | 恢复游戏 |
| “提示” | 高亮一个没有阻挡、可以发射的火箭 |
| “音效开 / 音效关” | 切换音效 |
| 普通关结算“下一关” | 进入下一关 |
| 结算或失败页“返回首页” | 回到开始页面 |
| 失败页“重新挑战” | 重开当前关卡 |
| 首页“继续探索” | 从 continue_level 指向的关卡初始布局开始 |
| 首页“新的探索” | 回第一关，并清空本次运行中的最佳纪录 |
| 关闭窗口 | 退出程序 |

继续探索不是恢复退出前的每枚火箭位置。最终通关返回首页后，本版仍会显示继续探索，点击后进入最后一关；尚未实现最终通关后隐藏此入口。

## 计时、纪录与当前限制

本关通关时比较用时，更短则更新 `best_times`。结算界面会提示新纪录；没有刷新时显示历史最佳。

- 纪录和进度只保存在内存中，退出程序后不保留，没有外部存档文件。
- 首页“新的探索”会调用 reset_progress，清空最佳纪录；游戏中重开当前关不会清空历史最佳。
- 暂停时停止火箭更新，恢复后扣除暂停时长；但暂停分支仍刷新 current_elapsed，暂停界面上的时间会变化，属于待修复的显示问题。

**运行不需要额外图片、音乐、音效或关卡资源文件。** 火箭、星球、星星、背景和界面由代码绘制；音效由 Python 和 Pygame 合成，未读取 WAV/MP3 等文件。音频初始化失败时，代码会禁用音效，仍可运行游戏。

中文字体优先从系统匹配，再尝试 Windows、macOS、Linux 的常见中文字体路径，最终使用默认字体。Windows 有微软雅黑或黑体时无需附带字体；如果系统缺少中文字体，可能显示方框。不要直接上传系统字体文件。若将来需要字体随包分发，应选择许可允许的字体并修改加载路径，本包未改动源码。

## 实现思路

- 火箭使用 `[row, col, direction, color_index]` 表示。
- get_blocking_arrow 沿朝向逐格扫描，返回最近阻挡物；无阻挡返回 None。
- 飞出动画完成后检查本关是否清空；碰撞动画负责移动、变色和回退。
- 游戏状态包括 start、game、pause、fail、level_complete。
- check_level_complete 生成结算信息，比较最佳时间，再进入结算界面。
- 音效通过采样函数生成波形，使用 pygame.mixer 播放，不依赖音频素材下载。
