# 一箭又一箭 · 太空探索

## 项目名称

**一箭又一箭 · 太空探索（Pixel Space Quest）**

## 游戏简介

《一箭又一箭 · 太空探索》是一款使用 Python 和 Pygame 开发的益智闯关小游戏。

游戏棋盘中分布着朝向不同方向的火箭。玩家需要判断火箭前进方向上是否存在其他火箭阻挡，并按照合适的顺序点击火箭，使所有火箭安全飞出棋盘。

游戏包含多个太空探索主题关卡，从地面发射、穿越大气层、近地轨道，一直到深空探索。游戏中包含关卡计时、最佳纪录、碰撞反馈、失误次数、提示、暂停、音效和关卡切换等功能。

## 开发环境

- Python 3
- Pygame
- Windows / macOS / Linux
- 推荐使用 VS Code 或 PyCharm 运行

## 新增与改进
1. 代码结构优化
将上一版本中集中在单个 main.py 文件里的代码进行模块化拆分，分别建立 main.py、game_screen.py、home_screen.py、audio_system.py 和 config.py。不同文件分别负责主程序、游戏界面、首页、音效和配置，使代码结构更加清晰，也更方便后续修改和维护。

2. 暂停菜单功能完善
上一版本的暂停界面主要只有“继续游戏”和“重新开始”功能，本版本进一步增加并完善了“继续探索”“重新开始本关”“从第一关开始”和“返回首页”等选项，让玩家在暂停后可以更加灵活地选择接下来的操作。

3. 游戏记录与计时功能完善
对关卡计时和成绩记录功能进行了优化，可以记录玩家每个关卡的完成时间和最佳成绩，并保存相关游戏记录。同时对暂停期间的计时进行了处理，使暂停时间不会被计算到关卡成绩中，让最终记录更加准确。

4. 界面与游戏体验优化
对首页、游戏界面、暂停界面和关卡完成界面进行了进一步优化，并完善按钮悬停、点击反馈和动画效果。同时保留并完善提示、失误次数、火箭飞行动画、碰撞效果、音效开关和多关卡探索等功能，使整个游戏流程更加完整、操作更加方便。

## 安装方法

首先确保电脑已经安装 Python。

安装 Pygame：

```bash
pip install pygame
```

下载或克隆本项目后，进入项目目录。

## 运行方法

运行游戏：

```bash
python main.py
```

## 游戏操作说明

### 开始游戏

在首页点击“新游戏”开始第一关。

如果已有游戏进度，可以点击“继续游戏”继续探索。

### 基本玩法

1. 观察棋盘中每个火箭的方向。
2. 判断该火箭前进方向上是否有其他火箭阻挡。
3. 如果没有阻挡，点击火箭后火箭会安全飞出棋盘。
4. 如果存在阻挡，错误操作会触发碰撞反馈并消耗失误次数。
5. 清除当前关卡的全部火箭即可完成关卡。

### 游戏功能

游戏界面提供：

- **重新开始**：重新开始游戏；
- **暂停**：打开暂停菜单；
- **提示**：提示当前可以安全发射的火箭；
- **音效开 / 音效关**：切换游戏音效。

暂停后可以：

- **继续探索**：返回当前游戏；
- **重新开始本关**：从当前关卡初始状态重新开始；
- **从第一关开始**：回到第一关重新开始探索；
- **返回首页**：退出当前关卡并返回首页。

也可以使用 **ESC** 键暂停或继续游戏。

## 游戏特色

- 7×7 游戏棋盘；
- 四个方向的火箭路径检测；
- 多关卡太空探索主题；
- 火箭飞行动画和碰撞动画；
- 失误次数机制；
- 提示功能；
- 暂停与重新开始功能；
- 每关计时与最佳纪录；
- 游戏音效开关；
- 最终关卡结束动画。

## 运行所需资源

本项目的主要画面、火箭、星球、星星、背景和音效均通过 Python / Pygame 代码绘制或生成，因此当前版本**不依赖外部图片或音频文件**。

`config.py` 会优先尝试读取：

```text
assets/Chinese.ttf
```

作为中文字体。如果没有该字体文件，程序会尝试使用操作系统中已有的中文字体，因此 `Chinese.ttf` 不是当前代码运行的强制资源。

## 项目文件说明

- `main.py`：程序入口、游戏状态切换和鼠标/键盘事件处理。
- `game_screen.py`：关卡数据、棋盘、火箭逻辑、碰撞、提示、暂停及关卡界面。
- `home_screen.py`：游戏首页及结尾动画。
- `audio_system.py`：游戏音效生成和音效开关。
- `config.py`：窗口、字体、颜色、按钮和通用绘制配置。
